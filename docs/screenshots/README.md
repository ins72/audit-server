Regenerated by `node tools/e2e/capture.js` (needs `pnpm build` first and Playwright; `E2E_SCALE=2` for 2x images). They come from the real production build in headless Chromium with a stubbed Stremio API, so they are reproducible and safe to share (demo account `demo@example.com`, no real data). Use them for progress reviews, docs and marketing drafts; retake them after UI changes.
